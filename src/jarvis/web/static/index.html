Home Assistant triggers — brief when you come downstairs, summary when you get home

Home Assistant calls Jarvis at these addresses (POST, with the token as Authorization: Bearer …). Each answers with a short speech text you can play on a speaker.

  • morning — sends today's brief now (once a day; BRIEF_TIME stays as the fallback)
  • home — “Welcome home”: the rest of today, parcels delivered or to collect, things due tomorrow
  • evening — sends the evening preview now (once a day)

Sharing to Jarvis

          

          
Jarvis only appears in Android's share menu when Chrome installed it as a full app
            (Chrome menu → Install app, not Add to home screen). A sign it worked: long-pressing the
            Jarvis icon shows Today, Tomorrow and Plan. If not, Google's servers probably
            couldn't fetch this site to build the app (for example a geo-block or IP allow-list in front of Jarvis),
            and Chrome made a plain shortcut instead.
