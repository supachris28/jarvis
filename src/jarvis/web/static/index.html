Sharing to Jarvis

Jarvis only appears in Android's share menu when Chrome installed it as a full app (Chrome menu → Install app, not Add to home screen). A sign it worked: long-pressing the Jarvis icon shows Today, Tomorrow and Plan. If not, Google's servers probably couldn't fetch this site to build the app (for example a geo-block or IP allow-list in front of Jarvis), and Chrome made a plain shortcut instead.
